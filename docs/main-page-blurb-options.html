Four ways to introduce the page. Each sits above the search box and the table, shown here with a couple of real rows for context. The wording is a first draft in every case — worth rewriting in your own voice, but the shape and the length are the things to judge. Remember this is embedded under the "Publications" heading on helixcentre.com, so the blurb doesn't need to say what the page is called.
Option A

One sentence

The lightest touch. Says what the summaries are and that they can be filtered, nothing more.

Plain-English summaries of research and projects from the Helix Centre. Use the search box, or select a theme, project or type of publication to filter the list.

Option B

Two sentences — what it is, then how to use it

Separates the purpose from the instructions, so neither gets lost in the other.

We write plain-English summaries of our research and projects, so that anyone can read about the work without needing a subscription or a background in the field.

Search by title, author or keyword, or click any theme, project or type of publication in the table to filter the list. Filters combine, and you can share a filtered view just by copying the link.

Things to weigh up

Nobody reads an intro to a table. People scan straight to the rows. That argues for the shortest version that still does the job, and for putting the filtering tip near the thing it describes — which is Option D's reasoning.

But filtering isn't discoverable. The themes and projects look like links, so some people will click them, but nothing says filters combine or that a filtered view can be shared. If you want that used, it has to be said somewhere — which is Option B's reasoning.

The blurb adds height to the embed. The iframe grows to fit, so a three-line intro pushes the first row further down the helixcentre.com page on every visit. Option A costs one or two lines; Option C costs five or six.

Worth deciding separately: whether this is also where you tell Helix staff how to submit. There's a form link in the site config that nothing currently points at. It could be a quiet line at the bottom of the intro, or left off the public page entirely.

If you want a recommendation: A or D. A if you want one tidy sentence; D if you'd rather the filtering tip sat next to the search box where it's most likely to be read. B is the one to pick only if filtering is a feature you actively want people using rather than merely discovering.
